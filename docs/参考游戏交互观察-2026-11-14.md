# 参考游戏交互观察（2026-11-14）

试玩了一款 2001 年的同类客栈经营游戏（繁体版），记录它的**交互方式和流程**，只借鉴玩法和交互，不搬它的美术、文字和角色。

## 一、开局流程

1. **标题画面就是菜单**：画面上摆着几件器物，每件对应一个功能（新游戏 / 读档 / 设置 / 退出），鼠标移上去会高亮，点击进入。没有传统的按钮列表。
2. **选角色**：三家客栈、三位掌柜，各有立绘和名字，选一个开始。
3. **开场戏**：在店内场景里直接演，人物走位，配合对话框。
   - 对话框：左边头像，下面是名字牌，右边台词，**一个字一个字地打出来**。
   - 对话框会出现在说话人附近（上方或下方），点击翻页，也会自动翻。
   - 剧情大意：女掌柜在等一个离开多年的人；伙计们打烊回家，她独自留下。用人物关系埋下主线悬念。
4. **解说员引导**：进入城镇地图后，一位"解说员"问你要不要听"过关要诀"。
   - 它先问几个是/否的问题，答完送一笔小奖励。
   - 然后分条讲要点：招人看什么属性、要留够明天的工钱（否则破产）、什么时候切到打烊、要研发新菜、多买饰品涨人气、注意动线。

## 二、城镇地图（休息 / 经营之外的时间）

- 左上是**日期栏**（年 / 月 / 日 / 刻），右边一个大按钮"开始营业"。
- 右下是**圆盘菜单**，悬停有文字提示，包括：
  - 杂货铺：培训道具，每件提升店员某项能力，外加向心力。
  - 店内摆设
  - 粮行
  - 比赛
  - 人力市场
  - 系统
- 地图上的建筑也能点，悬停时有描边高亮。
- **进一次店铺要花掉 1 刻时间**，去城里办事有时间成本。

## 三、各个界面

| 界面 | 交互要点 |
| --- | --- |
| 杂货铺 | 2 列 × 4 行商品卡（图标 + 名称 + 价格），可翻页。悬停时，底部"说明栏"滚动显示效果。 |
| 人力市场 | 6 张头像卡，只显示名字和薪资。**悬停听自我介绍**（性格 + 想应聘的职位），**属性要雇了才知道**。点头像后，卡片上弹出"聘用 ✓/✗"。 |
| 粮行 | 10 类食材各一行：数量、加减、总价、持有量、"买"。 |
| 摆设（布局） | 俯视网格，门口的格子画着**红 ×（不能摆）**；把东西拖到右下角回收桶就能卖掉。右侧另有收支表、人员表、菜单、粮仓四个入口。 |
| 人员表 | 一张大表：每人的职业 / 厨艺 / 计算 / 技巧 / 反应 / 敏捷 / 毅力 / 魅力 / 向心力 / 薪资，底部统计各职业人数。 |
| 菜单 | 每类菜一列：菜图、左右箭头切换、菜名、价格、"开始研发"。研发会消耗该类食材 30 份，**进度用一根燃烧的蜡烛表示**。 |
| 收支表 | **折线图**，标签页分收入 / 支出 / 纯利润 / 薪资总和 / 消费人数，横轴是星期一到日，可切"目前 / 上周"；下半部分是各类食材的用量图。 |
| 粮仓 | 每类食材的库存，以及"最低 / 最高买价"（价格会浮动）。 |
| 比赛 | 朝廷官员用对话说明规则：报名费 8000，冠军奖金 12000 外加一枚徽章，最后是否报名。 |

## 四、营业中

- 店内是 45° 斜视角，人物会走动；客人头上有**笑脸表示满意度**。
- 圆盘菜单换成营业用的一套：切到摆设、**切换营业中 / 打烊中**、显示满意度、显示时钟、文字讯息、显示客栈状态。
- **时钟**：右上角圆盘，指针走一圈，标出日月和当前刻数。
- **客栈状态窗**：日期、资金、人气度、用餐人次、徽章，配掌柜头像。
- 一天约 5 刻，每刻约 40 秒。到了晚上画面变暗。
- 切到"打烊中"后，门口立起牌子，店里的客人吃完才走。
- **工钱在新的一天开始时扣**；新的一天自动恢复营业。

| 应聘者自我介绍 | 人力市场每位应聘者有一句自我介绍，按本事分三档；有两成概率往高里吹一档，所以只能当参考。 |

## 六、还可以继续借鉴的

- 收支表改成折线图（按星期，可切本周 / 上周）。
- 研发进度用蜡烛 / 香燃烧的动画。
- 营业时的圆盘时钟。
- 布局编辑时，在禁止摆放的格子上画红 ×（目前是整体判定）。
- 标题画面做成"点器物进菜单"。
- 主动"打烊"开关：提早收工，省掉傍晚的食材浪费。
