# 云来客栈

一个原创的古风客栈经营游戏，用 Godot 4.7 制作。玩法参考了经典客栈经营类游戏的常见机制（周历与休假日、带属性的伙计、菜系研发、比赛晋级、访客事件），美术、人物、名字全部原创，画面全用代码绘制。

## 怎么打开

先装 **Godot 4.7**（免费）：<https://godotengine.org/download/>，Windows、Mac、Linux 都行。

**Windows**
- 直接玩：双击 `开始游戏.bat`
- 改游戏：双击 `在编辑器中打开.bat`，在 Godot 编辑器里按 F5 运行
- 两个 bat 默认找 `%LOCALAPPDATA%\Programs\Godot\` 下的 Godot，装在别处就改一下 bat 里的路径

**Mac**
1. 下载 macOS 版 Godot 4.7，解压后把 `Godot.app` 拖进「应用程序」文件夹
2. 第一次打开 Godot 时如果提示“无法验证开发者”，在「系统设置 → 隐私与安全性」里点「仍要打开」
3. 直接玩：双击 `开始游戏.command`；改游戏：双击 `在编辑器中打开.command`
   - 如果双击没反应，先在终端里进到项目文件夹执行一次 `chmod +x *.command`
4. 也可以不用脚本：打开 Godot → 「导入」→ 选本文件夹里的 `project.godot`

**从 GitHub 拿代码**（任何电脑）
```
git clone <仓库地址>
cd yunlai-inn
```
然后按上面的方式打开。`.godot/` 缓存文件夹不进仓库，Godot 第一次打开时会自动重建，稍等几秒即可。

## 玩法

**一周七天**：周一到周六营业，伙计们自己干活；第七天是休假日，可以进城办事。

**伙计**（右侧「伙计」页）：掌柜、厨师、跑堂、杂役四种职位，每人有能力值：

| 能力 | 作用 |
|---|---|
| 厨艺 | 厨师做菜、研发更快 |
| 计算 | 掌柜结账更快（没有掌柜，客人只能在桌边自己算账，占着桌子） |
| 技巧 | 跑堂走得快、手脚利索 |
| 反应 | 杂役照应得好，客人更沉得住气 |
| 魅力 | 厨师和掌柜招揽客人；跑堂让客人更满意 |
| 毅力 | 太低会偷懒 |
| 向心力 | 工钱低于本事会下降，太低会在休假日辞工；加薪、送道具能提高 |

营业日可以加薪；调职、辞退要等休假日。伙计每天干活会慢慢长本事。

**集市**：休假日大堂换成一条集市街，点铺子就能办事，点街尾「回店开张」进入下一周。粮行可以设「自动补货」，每个休假日自动把食材补到设定的数。

**食材**：分米面、菜蔬、肉禽、河鲜四类，每个菜系用一类（面食点心用米面，家常用菜蔬，烧肉汤品用肉禽，河鲜用河鲜）。行情每个休假日变动；菜蔬、河鲜每天打烊会放坏一些。

**节令**：每四周换一季。春天家常菜好卖，夏天面食好卖但东西坏得快，秋天客多、河鲜最受欢迎，冬天汤品最好卖、菜蔬贵。元宵、端午、中秋、除夕当天客人多、赏钱大方。

**剧情**：第三周起对门开了醉仙楼，抢走一成客人，之后还会挖人、造谣、下战书。擂台赢了，醉仙楼就关门。

**城镇**（只有休假日能去）：
- 粮行按类进食材、设各类的自动补货。营业日只能急购，价格翻倍
- 人力市场招人。应征者的本事要雇了才知道
- 木工坊添桌子、装修
- 杂货铺给选中的伙计买道具

**菜谱**：六个菜系，每系三道菜依次研发。研发由厨师在营业日推进，厨艺越高越快。可以用 －／＋ 调菜价。

**比赛**：五场比赛依次参加。休假日报名，下一周六天比成绩：
- 招待人数
- 收入
- 满意度
- 招牌菜份数

全部赢下就名扬天下。

**访客事件**：营业时会有说书先生、杂耍班子、赶考书生、地痞、美食家、游方郎中、落难名厨上门，由你决定接不接待。

**存档**：每到休假日（进集市时、回店开张前）自动存档。下次打开游戏点「读取存档」，回到最近那个休假日。营业日中途退出会丢掉这一周的进度。

快捷键：空格 暂停/继续，1 / 2 / 3 切换速度。

## 换成图片素材

把图片按 `art/素材说明.txt` 里的文件名放进 `art` 文件夹，就会自动替换掉代码画的人物、桌凳、地板和菜品。没放图片的部分继续用代码画，所以可以一样一样地换。素材的来源和授权记在 `art/CREDITS.txt`。

## 音效

切菜、炒菜、门铃、收钱、上菜、开张锣都用代码合成；店小二的吆喝在 `sfx/voice`。顶栏「声音」按钮可以开关。想换成真实录音，按 `sfx/音效说明.txt` 放同名 wav 即可。

## 代码结构

| 文件 | 内容 |
|---|---|
| `scripts/data.gd` | 数据表：食材、菜系、节令、剧情、伙计、道具、访客事件、比赛。**调数值改这里** |
| `scripts/main.gd` | 主控：周历、迎客、派活、后厨、结账、城镇、比赛、事件、画面、界面 |
| `scripts/worker.gd` | 伙计：按职位干活、偷懒 |
| `scripts/customer.gd` | 客人：落座、等待、吃饭、结账或生气离开 |
| `scripts/sfx.gd` | 音效：合成音效、读吆喝录音、声音开关 |
| `scripts/art.gd` | 图片素材加载：有图用图，没图用代码画 |
| `scripts/walker.gd` | 小人走路和画身体的共用代码 |
| `scripts/float_text.gd` | 飘字提示 |

## 自动测试

```
# Windows
Godot_v4.7.2-stable_win64_console.exe --headless --path . --fixed-fps 60 -- --autotest
# Mac
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --fixed-fps 60 -- --autotest
```

会快速模拟两周，把每个系统都操作一遍，最后打印 `[autotest] OK`。

## 导出成 exe

编辑器菜单「项目 → 导出」→ 添加「Windows Desktop」。第一次会提示下载导出模板，按提示下载后点「导出项目」即可。
